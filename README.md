# unit-converter-app
Android unit converter app built with Kotlin and Jetpack Compose
## Features
- Real-time conversion updates as you type
- Clean, modern, and responsive UI built with Jetpack Compose
- Input validation for accurate results
- Support for multiple measurement categories

## Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Platform:** Android

## What I Learned
Building this app strengthened my skills in Android development, state management, and real-time data handling while designing an intuitive user experience.
